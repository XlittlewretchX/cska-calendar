ЦСКА в вашем
календаре.

Одна подписка на матчи основной команды: чемпионат, кубки, сборы и товарищеские встречи. Расписание и результаты обновляются каждый день.

Подписаться на календарь ↗

Для iPhone, iPad и Mac. Если кнопка не открыла «Календарь», добавьте подписку по адресу:

https://xlittlewretchx.github.io/cska-calendar/calendar.ics

Даты могут уточняться

Предварительные диапазоны занимают несколько дней. После публикации даты и времени та же встреча обновится автоматически. Прошедшие матчи останутся вместе с результатами.

Как подключить

iPhone / iPad: «Календарь» → «Календари» → «Добавить календарь» → «Добавить подписной календарь».

Mac: «Календарь» → «Файл» → «Новая подписка на календарь». Выберите автообновление каждый час.

Добавьте подписку по ссылке, чтобы получать изменения. Разовый импорт файла не обновляется.

Данные официального сайта

История с 1992 года. Сведения о последнем успешном обновлении — в файле состояния.

Покрытие зависит от опубликованного расписания клуба; архив может быть неполным. Частоту получения изменений на устройстве определяет Apple.
